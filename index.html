🎯 Tujuan Pembelajaran

Setelah mengikuti pembelajaran menggunakan Statistika Explorer, peserta didik diharapkan mampu:

  • Mengidentifikasi hubungan antara dua variabel melalui data bivariat.
  • Menyajikan data dalam bentuk diagram pencar serta memahami pola hubungan yang terbentuk.
  • Menganalisis arah dan kekuatan hubungan antar variabel berdasarkan pola pada diagram pencar.
  • Menentukan dan menggunakan persamaan regresi linear untuk membuat prediksi berdasarkan data.
  • Menghitung dan menginterpretasikan koefisien korelasi untuk menjelaskan hubungan antar variabel.
  • Menerapkan konsep statistika dalam permasalahan nyata serta mengambil keputusan berdasarkan hasil analisis data.

📖 Petunjuk Penggunaan

Ikuti langkah-langkah berikut untuk menggunakan media pembelajaran Statistika Explorer:

  1. Mulai Pembelajaran
    Klik tombol "Mulai Eksplorasi" untuk memasuki halaman pembelajaran statistika.
  2. Pelajari Materi Secara Berurutan
    Pahami konsep mulai dari data bivariat, diagram pencar, interpretasi hubungan, regresi linear, hingga korelasi.
  3. Lakukan Eksplorasi Data
    Gunakan fitur Lab Data untuk memasukkan data, membuat diagram pencar, menghitung regresi, dan melihat hubungan antar variabel.
  4. Analisis Hasil
    Perhatikan pola grafik, persamaan regresi, dan nilai korelasi untuk memahami hubungan antar variabel.
  5. Kerjakan Evaluasi
    Uji pemahaman melalui tantangan konsep, interpretasi grafik, dan analisis studi kasus.
  6. Lakukan Refleksi
    Tuliskan pemahaman dan pengalaman belajar setelah menyelesaikan seluruh aktivitas pembelajaran.
💡 Tips Pembelajaran:
Jangan hanya menghafalkan rumus. Gunakan data, grafik, dan hasil analisis untuk menemukan makna dari hubungan antar variabel.
