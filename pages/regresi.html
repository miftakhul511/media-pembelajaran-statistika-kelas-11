📏 Misi 04: Regresi Linear

Membuat prediksi berdasarkan pola data

🎯 Permasalahan

Sebuah sekolah ingin mengetahui:

"Berapa perkiraan nilai siswa jika diketahui lama waktu belajar?"

📊 Data Pengamatan

Jam Belajar (X) Nilai (Y)
155
265
375
480
590

🧮 Langkah Perhitungan Regresi

1. Menghitung Rata-rata

\[ \bar{x}=\frac{\sum x}{n} \]

\[ \bar{y}=\frac{\sum y}{n} \]

2. Menghitung Koefisien Regresi

\[ b= \frac{ n\sum xy-(\sum x)(\sum y) } { n\sum x^2-(\sum x)^2 } \]

3. Menghitung Konstanta

\[ a=\bar{y}-b\bar{x} \]

4. Persamaan Regresi

y = a + bx

🧪 Eksperimen Prediksi

Masukkan jumlah jam belajar, kemudian lihat perkiraan nilai.

🤔 Pertanyaan Penyelidikan

1. Apakah garis regresi selalu melewati semua titik data?
2. Mengapa regresi dapat digunakan untuk memperkirakan nilai?
3. Apakah hubungan yang kuat berarti X menyebabkan Y?

💡 Konsep yang Kamu Temukan

Regresi linear adalah metode untuk membuat model hubungan antara dua variabel dengan menggunakan garis terbaik.

Model tersebut dapat digunakan untuk melakukan prediksi terhadap nilai yang belum diketahui.
